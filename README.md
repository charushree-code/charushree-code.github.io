# Charushree Anil — Portfolio

An interactive 3D portfolio built with three.js. Scroll to walk through the room.

Live site: https://charushree-code.github.io

## Files
| File | What it is | How often you'll touch it |
|---|---|---|
| `content.js` | Projects, skills, and certifications | Often: this is where you edit |
| `Charushree-Anil-Resume.pdf` | The resume behind "Download PDF" | Whenever your resume changes |
| `index.html` | The 3D room, layout, and the rest of the text | Rarely |

## Add a new project (2 minutes, all in the browser)
1. Open `content.js` on GitHub and click the pencil icon.
2. Copy the TEMPLATE block at the top of `projects`, paste it above the first project, and fill it in.
3. Use `status: "building"` while it's in progress (it shows an "In progress" badge), then change it to `""` when it's done.
4. Add your repo URL to `github`, and optionally a live link to `demo` and your Substack post to `writeup`.
5. Click **Commit changes**. The site updates in about a minute.

## Add a skill or certification
Add a quoted item to the right `skills` list, or a `{ name, url }` entry to `certifications`.

## Update the resume
Upload a new file named exactly `Charushree-Anil-Resume.pdf` (Add file → Upload files). It replaces the old one.

## Bigger edits
Press `.` on the repo page to open the full VS Code editor in your browser (github.dev).
If something breaks after an edit, open the commit history and click "Revert". Every version is saved.
